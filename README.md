# Homebrew tap for Findit

[Findit](https://seyon.xyz) is a local-first Mac file launcher with previews.

```sh
brew install --cask vineethraj-ai/tap/findit
```

Findit updates itself with Sparkle, so `brew upgrade` is not needed
(`auto_updates true`). Requires Apple silicon and macOS 13 Ventura or later.
